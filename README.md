# TreeNetSim — Имитационная модель древовидной локальной сети

Десктопное приложение на платформе WPF / C# для  имитационного моделирования процессов передачи данных в локальных вычислительных сетях с древовидной иерархической структурой.

Программа позволяет исследовать временные характеристики сети, задержки, длину очередей на коммутаторах и вероятность потери пакетов при различных нагрузках и конфигурациях.

## Ключевые возможности симулятора

- Имитационное моделирование сетей. Дискретно-событийный движок с использованием собственной приоритетной очереди событий на базе оптимизированного бинарного поиска.
- Пять математических моделей трафика. Генерация пакетов по распределениям: детерминированное, экспоненциальное, равномерное, нормальное и Парето.
- Два режима моделирования. Равномерная максимальная загрузка или моделирование по индивидуальной матрице адресации (с возможностью ручного ввода пакетов между конкретными узлами).
- Визуализация в реальном времени. Динамическое отображение движения пакетов по каналам связи, индикация переполнения очередей коммутаторов и анимация сброса пакетов при перегрузке буферов.
- Экспорт результатов. Возможность сохранения подробного хронологического лога событий и сводной статистики показателей эффективности сети в текстовый файл.

## Архитектура сети и правила маршрутизации

Топология сети представляет собой трехуровневое дерево:
- Центральный коммутатор (Маршрутизирует межсегментный трафик)
- Два локальных коммутатора ветвей (Маршрутизируют внутренний трафик сегментов)
- Набор рабочих станций (Генераторы и получатели трафика)
